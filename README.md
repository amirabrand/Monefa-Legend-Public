# Monefa Legend 🏰

> **بازی استراتژیک آنلاین در مرورگر** — سبک Travian، کاملاً فارسی

**Monefa Legend** یک بازی استراتژیک همیشه‌آنلاین است: با یک دهکده‌ی کوچک شروع می‌کنی، منابع تولید می‌کنی، ارتش آموزش می‌دهی و با هزاران بازیکن دیگر برای فتح «عجایب جهان» رقابت می‌کنی. اتحاد بساز یا فتح کن — انتخاب با توست.

---

## ✨ چه چیزهایی در انتظار توست؟

- 🏘️ **اقتصاد واقعی** — مدیریت چوب، خاک، آهن و گندم + دهکده‌های oasis
- 🏗️ **۳۰+ ساختمان** — از سربازخانه و بازار تا دیوار شهر و عجایب جهان
- ⚔️ **نبرد کامل** — حمله، غارت، پشتیبانی، کت‌آلت و حمله‌ی گروهی هماهنگ
- 🦸 **سیستم هیرو** — سطح‌گیری، مأموریت (Adventure)، حراج آیتم و مهارت‌ها
- 🛡️ **اتحادها** — فروم، پیام گروهی، پیمان و جنگ‌های مشترک
- 🗺️ **نقشه‌ی ۱۰۰×۱۰۰** — دنیایی زنده با دهکده‌ی بازیکنان واقعی
- 💎 **گیم‌گولد و Plus** — فروشگاه درون‌بازی و امکانات ویژه
- 🌐 **فارسی‌سازی کامل** — رابط کاملاً فارسی با تقویم جلالی

## 🚀 اجرا و نصب

کل بسته‌ی بازی (کد کامل + فایل نصب + دامپ دیتابیس) در **ریپوی خصوصی** [`Monefa-Legend`](https://github.com/amirabrand/Monefa-Legend) نگهداری می‌شود و روی هر سرور اوبونتو با **یک فرمان** نصب می‌شود:

```bash
git clone https://github.com/amirabrand/Monefa-Legend.git
cd Monefa-Legend
sudo bash install_ubuntu.sh --domain=game.example.com --admin-pass='رمز-قوی'
```

نصب‌کننده به‌صورت خودکار: Apache + MariaDB + PHP را نصب می‌کند، دیتابیس را می‌سازد، کانفیگ را بیرون از web root می‌نویسد، اکانت ادمین را ایجاد می‌کند و cron «ساعت بازی» را فعال می‌کند.

| بخش | آدرس |
|------|------|
| ورود به بازی | `/login.php` |
| **پنل مدیریت** | `/TdPaneLXP/` |

## 🔧 زیر ساخت

- PHP 8.1 – 8.3 + MariaDB + Apache (یا nginx)
- گرافیک کاملاً لوکال (بدون وابستگی به CDN خارجی)
- نصب‌کننده‌ی خودکار با حالت تعمیر (`install.php?mode=fix`)
- گزارش کامل ۲۱ دسته باگِ اصلاح‌شده در ریپو موجود است
